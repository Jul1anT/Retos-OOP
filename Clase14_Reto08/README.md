# Reto 8
Se implemento un iterador que facilita el recorrido de los ítems dentro de una orden.

## `OrderIterator`
Clase que permite iterar sobre los ítems en una orden:
- Implementa `__iter__()` y `__next__()` para recorrer los ítems de la orden de manera secuencial.
- Devuelve los ítems con su nombre, cantidad y precio.
